# Guía Cyberpunk 2077 · Cyberpunk 2077 Guide

Guía-compañera offline (PWA, ES/EN) de **Cyberpunk 2077: Ultimate Edition**
(juego base + Phantom Liberty), jugado en Nintendo Switch 2 con la Update 2.5:
misiones paso a paso, coleccionables con checklist, arsenal, jefes,
fragmentos, logros y personajes. Pensada para tenerla abierta mientras juegas.
El progreso (checklists y misión actual) se guarda en el dispositivo
(IndexedDB): sin cuentas, sin backend, funciona sin conexión una vez instalada.

An offline companion guide (PWA, Spanish/English) for Cyberpunk 2077:
Ultimate Edition. Spanish lives at the root, English under `/en/`.

Live: <https://artemiop.com/cyberpunk-2077-guide/>

```bash
npm install
npm run dev      # http://localhost:4321
npm run check    # gate: astro check + type-check + tests + prettier + build
```
